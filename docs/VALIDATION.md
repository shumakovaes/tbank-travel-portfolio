# Проверка проекта

Дата проверки: 5 ноября 2026 года.

- Полный расчёт выполнен на исходном CSV; контрольная сумма и учёт строк записаны в `reports/manifest.json`.
- Все 18 автоматических тестов прошли. Проверены границы окна конверсии, неполное наблюдение, пропущенные статусы, дубликаты заказов, бесконечные цены и неизвестные типы заказа. Полный пайплайн проверен на срезах без отелей, без авиабилетов, без успешных заказов, за один месяц, с пропусками дат отелей и с нулевой кросс-продажей.
- Сводки по продуктам и месяцам в SQL совпали с результатами pandas.
- Независимый расчёт через стандартную библиотеку Python (`scripts/verify_reference.py`) подтвердил суммы, медианы, когортную таблицу и три окна AIR → HOT: 93 / 20 836 (7 дней), 200 / 19 563 (30 дней), 308 / 17 800 (60 дней).
- Все 9 ячеек с кодом в ноутбуке выполнены последовательно без ошибок; результаты сохранены в ноутбуке.
- Все пять графиков просмотрены. HTML-отчёт проверен в браузере при ширине 1360 и 390 пикселей: изображения загружаются, горизонтального переполнения нет.

Это проверка воспроизводимости расчётов и отображения. Она не подтверждает полноту исходной выгрузки или причинный эффект предложенных продуктовых изменений.

## Исправления после проверки

- SQL-сверка корректно сопоставляет отсутствующие денежные показатели (`NULL`, `pd.NA`, `NaN`).
- Пустые таблицы сохраняют структуру; отчёт и пять графиков создаются даже без наблюдений для отдельных метрик. Ненаблюдаемая доля не подменяется нулём.
- При нулевой или отсутствующей базовой доле отчёт объясняет, почему размер эксперимента не рассчитан.
- Периоды в тексте определяются по данным; нет фиксированных утверждений о ноябре или декабре при анализе другого CSV.
- Подпись n у медианных цен отелей учитывает только успешные заказы с корректной ценой.
- На месячном графике показаны все календарные месяцы между границами выборки, включая месяцы без заказов.

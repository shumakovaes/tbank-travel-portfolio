# Источники и воспроизводимость

Первичный источник: [DANO 2024–2025](https://dano.hse.ru/data2024), раздел «Т-Банк: отели и авиабилеты». [Описание полей](https://dano.hse.ru/mirror/pubs/share/987926897.pdf).

Фактически проанализирована CSV-копия из [репозитория Kor4yz](https://github.com/Kor4yz/T-bank_analysis_hotels_and_air_travel), commit `d69b9db256cee03e6983d8b78e5b82d50b127401`, файл `data/dataset_travel.csv`, 25 206 124 байта. Соответствие копии полному оригинальному набору DANO побайтово не проверялось. Выводы относятся именно к этой копии.

SHA-256: `a8739c64927a7fc4a0398adac55ba8c033ffe7cd67ff42cbf7533bdf8a50c211`.

В исходном README ссылка ведёт на DANO 2022–2023. В новой версии она исправлена: описание нужного travel-набора находится на странице 2024–2025.

Лицензия исходного репозитория MIT с указанием Copyright (c) 2025 Kor4yz сохранена в `LICENSE`. Новая реализация использует исходную постановку и CSV, расчёты и документация переработаны. MIT для кода не интерпретируется как отдельное подтверждение прав на банковский датасет. CSV не включён в архив; загрузчик получает опубликованную копию по ссылке с проверкой контрольной суммы.

Публичные результаты содержат агрегаты. Клиентские ID, контакты, место рождения и индивидуальные профили не экспортируются.

## Поля, используемые в анализе

| Поле | Использование |
|---|---|
| `order_rk` | Проверка уникальности заказа |
| `client_rk` | Уникальные покупатели, когорты и последовательности покупок |
| `order_type_cd` | Отделение AIR/HOT от строк без заказа |
| `order_status_cd` | SUC и покрытие статуса |
| `created_dttm` | Месяц создания, якорь и окно кросс-продажи |
| `book_start_dttm`, `book_end_dttm` | Календарная глубина бронирования и длительность отеля |
| `nominal_price_rub_amt` | Номинальная стоимость бронирования в рублях |
| `promo_code_discount_amt` | Проверка полноты скидок |
| `hotel_city`, `avia_arr_city` | Популярные направления по числу успешных заказов |

В официальном описании `book_start_dttm` определён для отелей. Поэтому новая версия исследует глубину бронирования только HOT и не переносит эту трактовку на авиабилеты без подтверждения.
